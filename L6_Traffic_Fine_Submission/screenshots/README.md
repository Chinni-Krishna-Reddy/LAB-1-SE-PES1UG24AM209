# Required terminal screenshots

The assignment asks for terminal screenshots showing the final results (at least
90% code coverage and at least 90% branch coverage).

These cannot be truthfully captured from your computer in advance. After running
the two commands in the root README, take a screenshot of the terminal showing:
1. The pytest result and `coverage report -m` for code coverage.
2. The pytest result and branch-enabled `coverage report -m` for branch coverage.

Save them in this folder as:
- `code_coverage.png`
- `branch_coverage.png`

Make sure the filename and TOTAL coverage percentage are readable in each image.
